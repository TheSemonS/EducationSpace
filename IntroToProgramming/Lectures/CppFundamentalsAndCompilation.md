## 1. Понятие программы и процесс компиляции

> **Программа** — это упорядоченный алгоритм, записанный на определенном языке программирования и предназначенный для последующего выполнения электронно-вычислительной машиной (компьютером).

Процесс перевода понятного человеку кода в понятный процессору машинный код выполняет **транслятор**. Трансляторы делятся на два ключевых типа:
* **Компиляторы** — переводят весь текст программы целиком в готовый исполняемый файл перед запуском.
* **Интерпретаторы** — выполняют код построчно (пошагово) непосредственно в процессе работы программы.

### Конвейер работы компилятора
```text
[Исходный код (.cpp)] 
         │
         ▼
[Синтаксический контроль] ──(при ошибке)──> [Возврат к редактированию]
         │
         ▼
[Генератор машинного кода]
         │
         ▼
[Исполняемая программа (.exe)]
```

### Основные задачи компилятора
- [ ] **Синтаксический анализ:** Полная проверка исходного текста программы на соответствие правилам грамматики языка.
- [ ] **Генерация кода:** Создание низкоуровневого машинного кода (выполняется исключительно в том случае, если на этапе анализа не было обнаружено ни одной ошибки).

### Фундаментальные триады языка программирования
* **Алфавит (Набор символов)** — разрешенный к использованию базисный набор символов, из которых строятся элементы кода.
* **Синтаксис** — строгая система правил построения синтаксических конструкций и выражений языка.
* **Семантика** — смысловое значение и логика выполнения каждой конструкции языка.

### Историческая справка и авторы
* **Деннис Ритчи (Dennis M. Ritchie):** Создатель языка C (1972 г., Bell Labs). Цель — написание операционной системы UNIX.
* **Бьёрн Страуструп (Bjarne Stroustrup):** Автор языка C++ (1979 г.). Добавил в C поддержку классов, заложив основу объектно-ориентированного программирования (ООП).
* **Б. Керниган и Д. Ритчи:** Авторы классического учебника-руководства по языку C (издания 1978 и 1985 годов), ставшего неофициальным эталоном (K&R C).

## 2. Стандарты и методология разработки

### Хронология и эволюция стандартов
* **C89 / C90** — первый официальный международный стандарт ANSI/ISO для чистого языка C.
* **C++ (на базе C89)** — ранняя стандартизация C++ с сохранением полной обратной совместимости с языком C.
* **C++99 (C99)** — обновление стандартов C, добавившее в язык новые типы данных, встроенные функции и улучшенную работу с массивами.
* **C++11 (ISO/IEC 14882:2011)** — масштабный стандарт («Современный C++»), принесший автоматическое выведение типов (`auto`), лямбда-выражения, умные указатели и поддержку многопоточности.

### Принципы структурного программирования
> **Теорема Бёма — Якопини (базовый постулат):** любая программа, создаваемая без использования запутанного оператора безусловного перехода `goto`, может быть спроектирована с помощью комбинации всего трех базовых управляющих конструкций:
> * **Последовательность** — выполнение команд строго друг за другом (линейно).
> * **Ветвление** — выбор пути выполнения в зависимости от истинности логического условия.
> * **Цикл** — многократное повторение блока команд до тех пор, пока условие остается истинным.
> * **Подпрограммы (Функции)** — логическое выделение именованных частей кода.

* 💡 **Парадигма разработки:** написание ПО в рамках структурного подхода всегда ведется пошагово по принципу **«сверху вниз»** (декомпозиция от крупных абстрактных модулей к простейшим инструкциям).

## 3. Анатомия программного текста: Лексемы

> **Лексема (Token)** — это минимальная неделимая структурная единица текста программы, которая распознается компилятором как единый смысловой элемент. Разделение лексемы на части уничтожает её смысл.

<details>
<summary>🔍 Развернуть классификацию лексем в C++</summary>

* **Свободно выбираемые идентификаторы:** Имена, которые программист дает переменным, функциям и классам (например, `myVariable`, `calculate_sum`).
* **Служебные (ключевые) слова:** Зарезервированные языком термины, выполняющие строгие функции (например, `int`, `if`, `while`, `return`).
* **Константы:** Фиксированные явные значения (например, `42`, `3.1415`).
* **Строковые литералы:** Текстовые строки, заключенные в двойные кавычки (например, `"Hello, World!"`).
* **Знаки операций:** Символы арифметических, логических и битовых действий (например, `+`, `-`, `*`, `/`, `&&`, `==`).
* **Разделители:** Символы, разграничивающие конструкции кода (например, `;` — конец инструкции, `,`, круглые `()` и фигурные `{}` скобки).
</details>

### Фазы обработки исходного текста
* **Препроцессорные директивы:** Команды, начинающиеся с символа `#` (например, `#include`, `#define`). Они обрабатываются до компиляции, подставляя тексты файлов или заменяя макросы.
* **Описания (Объявления):** Информируют компилятор о существовании, типе и имени объекта или функции, сигнатура которых полностью раскрыта в другом месте программы (или в стороннем файле).
* **Определения:** Выделяют физическую память под переменные и содержат непосредственный исполняемый код функций.

## 4. Конвейер сборки и состав проекта

### Схема сборки проекта (Build Pipeline)
```text
 [Исходный код (.cpp)] + [Заголовочные файлы (.h)]
                        │
                        ▼
                [ Препроцессор ]
                        │  (разворачивает директивы)
                        ▼
             [ Полный текст программы ]
                        │
                        ▼
                [  Компилятор  ]
                        │  (переводит в машинный код)
                        ▼
             [ Объектный код (.obj / .o) ] + [ Стандартные библиотеки ]
                                            │
                                            ▼
                                    [ Компоновщик (Линкер) ]
                                            │  (связывает код и библиотеки)
                                            ▼
                                 [ Исполняемая программа (.exe) ]
```

### Структурный состав проекта C++
* **Проект:** представляет собой совокупность одного или нескольких файлов (исходного кода `.cpp` и заголовочных файлов `.h`), компилируемых вместе.
* **Функция:** Логически изолированный, именованный блок кода, предназначенный для решения локальной подзадачи.
* **Главная функция (`main`):** Обязательная функция, выступающая единственной **точкой входа** в программу. Без неё сборка исполняемого файла невозможна.

```cpp
// Пример простейшего обогащенного каркаса программы на C++
#include <iostream> // Препроцессорная директива

int main() { // Главная функция (точка входа)
    std::cout << "Программа успешно запущена!" << std::endl;
    return 0; // Завершение программы
}
```
