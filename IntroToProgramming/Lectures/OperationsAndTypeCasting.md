## 1. Структурные элементы выражения и классификация операций

Для построения логики вычислений внутри текста программы необходимо разграничивать фундаментальные понятия:
* **Операнд** — дискретная неделимая лексема (переменная, константа, вызов функции), к которой непосредственно применяется программная операция.
* **Оператор** — законченная синтаксическая конструкция языка, посредством которой задается один конкретный шаг (действие) вычислительного процесса.
* **Разделители** — специализированные символы, предназначенные для физического разграничения ключевых слов и пользовательских идентификаторов в коде.

### Системная классификация операций
* **По количеству операндов, участвующих в действии:**
  * *Бинарные* — выполняются над двумя независимыми операндами (например, `a + b`).
  * *Унарные* — применяются строго к одному операнду (например, унарный минус `-x`).
* **По функциональному назначению (виды операций):**
  * Операция присваивания
  * Арифметические операции
  * Битовые операции сдвига
  * Операции отношения (сравнения)
  * Логические операции

## 2. Операция присваивания и явное приведение типов

Операция присваивания обозначается одиночным символом `=` и выполняется процессором строго в два последовательных технологических этапа:
1. Полностью вычисляется значение математического или логического выражения, стоящего в правой части.
2. Итоговый результат записывается в ячейку памяти операнда (объекта), стоящего в левой части.

* **Формальный шаблон:** `объект = выражение;`

### Синтаксис явного приведения типов
В случае если объект в левой части операции присваивания и результирующий тип выражения в правой части не совпадают по разрядности или типу, во избежание потери данных или предупреждений компилятора используется операция явного приведения типа.

* **Формальный шаблон:** `объект = (целевой_тип) выражение;`

### Практические примеры применения
```cpp
// Пример 1: Стандартное присваивание
int a = 4;
int b;
b = a + 2; // b принимает значение 6

// Пример 2: Явное приведение типов (type casting)
float a = 241.5f;
int b;
b = (int)a % 2; // b принимает значение 1
// Пояснение: Перед вычислением остатка от деления (%) вещественное число 'a' 
// принудительно отсекает дробную часть и превращается в целое число 241.
// Именно поэтому 241 % 2 = 1.
```

## 3. Арифметические операции и операции замещения

### Базовые бинарные арифметические операции
* `*` — операция умножения операндов.
* `/` — деление (для целочисленных типов — деление нацело с отсечением остатка).
* `+` — сложение.
* `-` — вычитание.
* `%` — операция вычисления остатка от деления (применима исключительно к целочисленным операндам).

### Основные унарные операции
* `++` — инкремент (увеличение значения операнда ровно на 1).
* `--` — декремент (уменьшение значения операнда ровно на 1).

### Комплексные операции замещения (составное присваивание)
Для оптимизации генерации машинного кода и сокращения записи используются совмещенные операторы:

| Сокращенная запись | Полный математический эквивалент |
| :--- | :--- |
| `об *= выр;` | `об = об * выр;` |
| `об /= выр;` | `об = об / выр;` |
| `об += выр;` | `об = об + выр;` |
| `об -= выр;` | `об = об - выр;` |
| `об %= выр;` | `об = об % выр;` |
