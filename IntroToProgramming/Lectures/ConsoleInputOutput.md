## 1. Синтаксис потокового вывода

Оператор `<<` позволяет выстраивать цепочки последовательного вывода различных типов данных в один поток, автоматически приводя их к строковому виду.

* **Обобщенный синтаксический шаблон вывода:**
  ```cpp
  std::cout << значение_1 << значение_2 << значение_3;
  ```

### Пример последовательного извлечения данных
```cpp
int n;
char j;

std::cin >> n >> j; // Множественный ввод: сначала считывается целое число, затем один символ
std::cout << "Значение n равно " << n << " j = " << j; // Комбинированный вывод текста и переменных
```

## 2. Локализация интерфейса консоли

По умолчанию стандартная консоль Windows и некоторых других операционных систем некорректно отображает кириллические символы (русский алфавит), выводя вместо них нечитаемые символы («кракозябры»). Для исправления этого поведения применяется принудительная локализация среды выполнения.

> **Функция `setlocale`** — системная функция из заголовочного файла `<clocale>` (`<locale.h>`), предназначенная для настройки текущих языковых и региональных параметров программы.

### Практическая реализация каркаса программы на C++

Ниже представлены два равносильных варианта организации исходного кода программы.

<details>
<summary>🔍 Развернуть Вариант 1: Использование явного указания пространства имен (std::)</summary>

Данный подход является наиболее академически строгим, так как исключает потенциальные конфликты имен в крупных программных проектах.

```cpp
#include <iostream>
#include <locale.h> // Подключение заголовка функций локализации

int main() {
    // Установка кодировки для корректного вывода русского текста
    setlocale(LC_ALL, "Russian"); 
    
    int n;
    
    std::cout << "Введите n: ";
    std::cin >> n;
    std::cout << "Значение n равно: " << n << std::endl; // std::endl очищает буфер и переносит строку
    
    return 0;
}
```
</details>

<details>
<summary>🔍 Развернуть Вариант 2: Использование глобальной директивы using namespace std</summary>

Этот вариант сокращает объем кода за счет автоматического импорта всех идентификаторов из стандартного пространства имен `std` в глобальную видимость.

```cpp
#include <iostream>
#include <locale.h>

using namespace std; // Глобальное подключение пространства имен std

int main() {
    setlocale(LC_ALL, "Russian");
    
    int n;
    
    cout << "Введите n: ";
    cin >> n;
    cout << "Значение n равно: " << n << endl;
    
    return 0;
}
```
</details>
