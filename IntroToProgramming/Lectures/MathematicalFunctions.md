## 1. Подключение математических функций

Для использования стандартных тригонометрических, степенных и других математических функций в C++ необходимо подключить заголовочный файл `<cmath>`.

* **Определение математических констант:** Для получения доступа к стандартным встроенным константам (например, числу $\pi \approx 3.14159$ через макрос `M_PI`), в среде разработки Microsoft Visual C++ перед директивой подключения `<cmath>` необходимо обязательно объявить специальный макрос препроцессора:
```cpp
#define _USE_MATH_DEFINES
#include <cmath>
```

## 2. Типы преобразования данных

При выполнении арифметических операций над операндами различных типов компилятор выполняет приведение их к единому типу. Преобразования разделяются на:
1. **Явные преобразования** — намеренно и жестко задаются программистом в коде.
2. **Неявные преобразования (автоматическое приведение)** — выполняются компилятором автоматически по правилам расширения типов (от менее емкого типа к более емкому, чтобы избежать потери точности).

### Правила неявного приведения при делении (`/`)

| Тип операнда 1 | Тип операнда 2 | Тип итогового результата | Пояснение |
| :--- | :--- | :--- | :--- |
| `float` | `float` | `float` | Стандартное вещественное деление |
| `float` | `int` | `float` | Переменная типа `int` неявно приводится к `float` перед делением |
| `int` | `float` | `float` | Переменная типа `int` неявно приводится к `float` перед делением |
| `int` | `int` | `int` | **Целочисленное деление** (дробная часть полностью отбрасывается) |

## 3. Способы явного преобразования типов в C++

Язык C++ поддерживает три фундаментальных механизма для принудительного изменения типа данных выражения:

- [ ] **Приведение типов в C-style (классический стиль):** Исторический способ, унаследованный из языка C. Из-за лаконичного синтаксиса его называют «обозначением приведения».  
  *Синтаксис:* `(целевой_тип) выражение` (например, `(int)myFloat`).
- [ ] **Функциональное приведение типов:** Запись преобразования в форме вызова функции, где аргументом выступает приводимое выражение.  
  *Синтаксис:* `целевой_тип(выражение)` (например, `int(myFloat)`).
- [ ] **Специализированные операторы преобразования типов (C++ style cast):** Наиболее безопасный и рекомендуемый стандартом способ. Включает в себя явные строго контролируемые компилятором операторы:
  * `static_cast<целевой_тип>(выражение)` — для стандартных логически связанных преобразований (например, из вещественного в целое).
  * `dynamic_cast` — для безопасного приведения типов по иерархии наследования классов.
  * `const_cast` — для удаления или добавления модификатора `const`.
  * `reinterpret_cast` — для низкоуровневого переинтерпретирования битовой сетки памяти.
