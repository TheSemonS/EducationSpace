## 1. Безопасный форматированный ввод данных

При использовании функции форматированного ввода `scanf_s` необходимо строго соблюдать синтаксический регламент передачи аргументов.

* **Синтаксис вызова:** `scanf_s("строка_формата", &переменная_1, &переменная_2, ...);`
* **Спецификатор формата:** Символ `%` определяет начало управляющего спецификатора.
* ⚠️ **Критически важное правило:** В качестве аргументов функции `scanf_s` могут выступать **только адреса объектов** программы (переменных), но не их прямые значения.

> **Амперсанд (`&`)** — это унарная операция взятия адреса ячейки памяти, в которой физически хранится переменная.

### Пример реализации ввода для различных типов данных
```cpp
#include <cstdio> // Подключение базовой библиотеки ввода-вывода C-style

int main() {
    int n;          // Целочисленный тип
    double z, x;    // Вещественные типы двойной точности

    // Безопасное считывание трех значений: одного целого и двух вещественных
    scanf_s("%d %lf %lf", &n, &z, &x); 
    
    return 0;
}
```

## 2. Стандартные потоки ввода/вывода: Библиотека iostream

Современный стандарт языка C++ предоставляет альтернативный, объектно-ориентированный механизм работы со стандартными потоками.

> **Библиотека `<iostream>`** — специализированный заголовочный файл стандартной библиотеки C++, определяющий три базовых стандартных потока управления.

### Перечень стандартных потоков ЭВМ
* `std::cin` — **Стандартный входной поток** (соответствует стандартному потоку ввода `stdin` в чистом языке C). По умолчанию связан с клавиатурой.
* `std::cout` — **Стандартный выходной поток** (соответствует потоку вывода `stdout` в языке C). По умолчанию выводит данные на экран терминала.
* `std::cerr` — **Стандартный поток вывода сообщений об ошибках** (соответствует неспуферизованному потоку `stderr` в языке C). Используется для немедленного отображения диагностических сообщений.

### Базовые операторы перенаправления потоков
Для реализации операций ввода-вывода (`in` / `out`) в C++ перегружены два оператора побитового сдвига:
* `>>` — **Операция «получить из потока»**. Извлекает данные из входного потока и записывает их в переменную (например, `cin >> n;`).
* `<<` — **Операция «поместить в поток»**. Направляет текстовое или бинарное значение переменной в выходной поток (например, `cout << n;`).
