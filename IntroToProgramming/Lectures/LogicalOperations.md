## 1. Логический тип данных и базовые операции

В языке программирования C++ для работы с логическими величинами используется специализированный тип данных `bool`. Значения логического типа интерпретируются вычислительной системой следующим образом:
* `1` — Истина (`true`)
* `0` — Ложь (`false`)

### Основные логические операции (Булева алгебра)
* `&&` — **Конъюнкция / Логическое «И»** (бинарная операция). Возвращает значение `true` только тогда, когда оба операнда истинны.
* `||` — **Дизъюнкция / Логическое «ИЛИ»** (бинарная операция). Возвращает значение `true`, если хотя бы один из операнда истинен.
* `!` — **Инверсия / Логическое «НЕ»** (унарная операция). Меняет значение операнда на противоположное.

<details>
<summary>🔍 Развернуть программу демонстрации таблиц истинности</summary>

```cpp
#include <iostream>

using namespace namespace std;

int main() {
    bool a1 = true, a2 = false, a3 = true, a4 = false;
    
    // Включение текстового вывода true/false вместо 1/0
    cout << boolalpha; 
    
    cout << "--- Таблица истинности логического И (&&) ---" << endl;
    cout << "true && false: " << (a1 && a2) << endl;
    cout << "false && true: " << (a2 && a1) << endl;
    cout << "true && true: " << (a1 && a3) << endl;
    cout << "false && false: " << (a2 && a4) << endl;
    
    cout << "\n--- Таблица истинности логического ИЛИ (||) ---" << endl;
    cout << "true || false: " << (a1 || a2) << endl;
    cout << "false || false: " << (a2 || a4) << endl;
    
    cout << "\n--- Таблица истинности логического НЕ (!) ---" << endl;
    cout << "!true: " << (!a1) << endl;
    cout << "!false: " << (!a2) << endl;
    
    return 0;
}
```

## 2. Практическая задача: Принадлежность точки области

> **Задание:** Дана точка $A$ с координатами $(x, y)$. Составить программу, которая выводит `true`, если точка принадлежит заштрихованной области, и `false` в противном случае.

### Математическое описание области (окружность радиуса 5 и полоса)
Точка находится внутри окружности радиуса $R=5$ с центром в начале координат, если выполняется условие $x^2 + y^2 \le 25$. При этом координата $x$ должна лежать вне интервала $(-3; 3)$, то есть $x \le -3$ или $x \ge 3$.

### Программная реализация на C++
```cpp
#include <iostream>

int main() {
    double x, y;
    
    std::cout << "x = "; std::cin >> x;
    std::cout << "y = "; std::cin >> y;
    
    // Вывод результата в формате true/false
    std::cout << std::boolalpha << ((x * x + y * y <= 25) && (x <= -3 || x >= 3)) << std::endl;
    
    return 0;
}
```
*💡 Трассировочный пример:* При $x = 4, y = 1$ выражение принимает значение `true` (так как $16 + 1 \le 25$ и $4 \ge 3$).

## 3. Побитовые логические и сдвиговые операции

Побитовые операции выполняются непосредственно над отдельными битами (разрядами) целочисленных данных в их двоичном представлении.

### Побитовые логические операции
* `&` — **Побитовое И (Bitwise AND / Конъюнкция):** Бинарная операция. Результат в разряде равен `1` тогда и только тогда, когда соответствующие биты обоих операндов равны `1`.
* `|` — **Побитовое ИЛИ (Bitwise OR / Дизъюнкция):** Бинарная операция. Результат в разряде равен `1`, если хотя бы один из соответствующих битов операндов равен `1`.
* `^` — **Побитовое исключающее ИЛИ (XOR):** Бинарная операция. Результат в разряде равен `1` тогда и только тогда, когда только один из соответствующих битов операндов равен `1`.
* `~` — **Побитовое НЕ (Bitwise NOT / Инверсия):** Унарная операция. Инвертирует каждый разряд операнда (заменяет `1` на `0` и наоборот).

### Сдвиговые операции
Используются для смещения битовой сетки значения на заданное количество разрядов.
* `>>` — **Побитовый сдвиг вправо:** Сдвигает биты операнда вправо. Физически эквивалентно делению числа на $2$ в степени количества разрядов.
* `<<` — **Побитовый сдвиг влево:** Сдвигает биты операнда влево, освобождающиеся младшие разряды заполняются нулями. Физически эквивалентно умножению числа на $2$ в степени количества разрядов.

* **Синтаксический шаблон:** `объект = выражение_операнд << количество_разрядов;`
