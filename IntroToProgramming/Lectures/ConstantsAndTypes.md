## 1. Понятие константы и способы объявления

> **Константа (Литерал)** — это ограниченная последовательность символов алфавита языка программирования, представляющая собой неизменяемое в процессе выполнения программы выражение фиксированного объекта предметной области.

В современном языке программирования C++ существует два фундаментальных способа инициализации константных величин:

* **Способы представления констант:**
  * **С помощью препроцессорной директивы `#define`:** Создает текстовый макрос, который на этапе препроцессинга слепо заменяет все вхождения идентификатора на указанное значение. Выделения физической памяти в стеке не происходит.
    * *Синтаксис:* `#define ИМЯ_МАКРОСА значение` (например, `#define MAX 100`). Обратите внимание: точка с запятой в конце строки не ставится.
  * **С использованием спецификатора (ключевого слова) `const`:** Объявляет полноценную переменную с явным указанием типа данных, защищенную от записи. Компилятор блокирует любые попытки изменения этого значения.
    * *Синтаксис:* `const Тип Данных ИмяПеременной = Значение;` (например, `const int n = 10;`).

## 2. Архитектура вещественных констант

Вещественные константы (числа с плавающей точкой) по умолчанию интерпретируются компилятором как числа двойной точности с типом данных `double`. Они могут быть записаны в двух форматах:
1. **Формат с фиксированной точкой:** Стандартное представление числа, где целая и дробная части разделены точкой (например, `3.14159`).
2. **Экспоненциальная (научная) нотация:** Представление числа в виде мантиссы и целочисленного порядка (экспоненты) после символа `e` или `E`. Применяется для записи экстремально больших или малых величин.

### Правила сокращения вещественной записи
При написании констант вещественного типа допускается поочередный пропуск одной из составляющих (но не обеих частей сразу):
- [ ] Можно опустить целую или дробную часть (например, `.5` эквивалентно `0.5`, а `3.` эквивалентно `3.0`).
- [ ] Можно опустить точку или символ экспоненты `e` / `E` вместе со знаком порядка.

| Примеры вещественных констант | Математический смысл |
| :--- | :--- |
| `345.` | $345.0$ |
| `3.14159` | $\pi \approx 3.14159$ |
| `2.1E5` | $2.1 \cdot 10^5 = 210000.0$ |
| `.123E3` | $0.123 \cdot 10^3 = 123.0$ |
| `4037e-5` | $4037 \cdot 10^{-5} = 0.04037$ |

## 3. Символьные и строковые константы

> **Символьная константа** — это одиночный символ, заключенный в строго одинарные кавычки (апострофы, например, `'z'`). Имеет базовый целочисленный тип данных `char` и занимает в оперативной памяти ровно 1 байт.

Для работы с невидимыми управляющими ASCII-кодами, не имеющими прямого графического представления на экране монитора, используются **escape-последовательности**, синтаксис которых начинается с символа обратного слеша `\`.

### Примеры записи символьных констант
* Стандартные символы: `'a'`, `'B'`, `'7'`, `'d'`, `'?'`.
* Символьные коды в восьмеричной системе: `'\141'`, `'\102'`, `'\75'`, `'\133'`, `'\144'`.
* **Управляющий символ «системный гудок» (Audio Bell):** `'\a'` или его восьмеричный эквивалент `'\07'`.
* **Управляющий символ переноса строки (Line Feed):** `'\n'` или его шестнадцатеричный эквивалент `'\x0A'`.

> **Строковая константа (Строковый литерал)** — это произвольная упорядоченная последовательность символов, заключенная в двойные кавычки (например, `"Текст программы"`). Внутри строковых литералов допускается использование любых управляющих escape-последовательностей (например, `"Строка 1\nСтрока 2"`).

## 4. Перечислимые константы (Тип enum)

Для повышения читаемости исходного кода и явного именования дискретных состояний системы используется ключевое слово `enum`.

> **Перечисление (`enum`)** — это пользовательский целочисленный тип данных, состоящий из фиксированного набора именованных констант, которые внутренне кодируются компилятором как обычные целые числа.

### Варианты объявления и синтаксиса перечислений
* **С автоматической нумерацией:** (Идентификаторы получают порядковые индексы начиная с 0).
  `enum day {sun, mon, tue, wen, thu, fri, sat};`  
  *(Где sun = 0, mon = 1, tue = 2 и т.д.)*
* **Логический тип (флаги):**
  `enum flag {false, true};`  
  *(false = 0, true = 1)*
* **С явным указанием значений:**
  `enum {one = 1, two = 2, three = 3};`
* **С комбинированным смещением:**
  `enum number {a = 54, b, c = 60, d = c + 5};`  
  *(Где a = 54, b автоматически увеличивается до 55, c принудительно равно 60, а d вычисляется как 60 + 5 = 65)*
