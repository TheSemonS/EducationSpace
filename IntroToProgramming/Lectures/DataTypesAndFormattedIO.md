## 1. Понятие типа данных и классификация в C++

> **Тип данных** — это базовая характеристика переменной или константы, которая строго определяет:
> 1. Диапазон (интервал) или конечное множество допустимых значений, которые могут быть сохранены.
> 2. Допустимый набор операций и функций, разрешенных для применения к данному объекту.
> 3. Объем оперативной памяти (в байтах), выделяемый операционной системой под хранение значения.

### Полная иерархическая структура классификации данных

* **По признаку изменчивости:**
  * **Константы** — значения, жестко зафиксированные в коде, которые гарантированно не могут быть изменены в процессе выполнения программы.
  * **Переменные** — именованные области памяти, значения которых могут динамически перезаписываться во время работы приложения.
* **По внутренней структуре:**
  * **Простые (Скалярные / Базовые)** — содержат в себе ровно одно атомарное значение.
  * **Структурированные (Составные)** — объединяют группы элементов (например, массивы, структуры `struct`, классы `class`).
* **По физико-логической природе:**
  * **Целые** — знаковые и беззнаковые дискретные числа.
  * **Вещественные** — числа с плавающей запятой. Могут быть представлены в экспоненциальной (научной) нотации.
    * *Пример математического соответствия:* 
      \[123 = 1.23 \cdot 10^2 \implies \text{в коде: } 1.23\text{e}2\]
      \[0.0123 = 1.23 \cdot 10^{-2} \implies \text{в коде: } 1.23\text{e}-2\]
  * **Логические** — принимают исключительно значения Истина (`true`) или Ложь (`false`).
  * **Символьные** — одиночные знаки в кодировке ASCII.
  * **Перечисления (`enum`)** — пользовательские наборы именованных целочисленных констант.

## 2. Базовые примитивные типы данных в C++

| Ключевое слово | Описание типа | Типичный размер в памяти | Диапазон значений |
| :--- | :--- | :--- | :--- |
| `char` | Символьный тип | 1 байт | от -128 до 127 (коды ASCII) |
| `int` | Целочисленный тип | 4 байта (на 32/64-бит ОС) | от -2 ⋅ 10⁹ до +2 ⋅ 10⁹ |
| `float` | Числа с плавающей точкой | 4 байта | Одинарная точность (7 значащих цифр) |
| `double` | Числа с плавающей точкой | 8 байт | Двойная точность (15-16 значащих цифр) |

## 3. Форматированный ввод и вывод данных

Для вывода и ввода данных используются строки форматирования. Текст управляющей строки форматирования может быть сформирован из следующих компонентов:
- [ ] Символы национальных алфавитов (латинский, русский и т.д.) для прямого вывода на экран.
- [ ] Цифры и знаки препинания.
- [ ] **Управляющие (escape) последовательности:** Специальные символы (например, `\n` — переход на новую строку, `\t` — горизонтальная табуляция).
- [ ] **Спецификаторы формата:** Указывают компилятору, в каком виде нужно интерпретировать двоичные данные переменной при вводе или выводе.

### Обобщенный формат спецификатора (шаблон)
```text
% [ширина_поля] . [точность] [спецификатор_типа]
```
* **Ширина поля:** Задает минимальное количество позиций, которое займет выводимое значение (если символов меньше, они дополняются пробелами).
* **Точность:** Для вещественных чисел указывает строгое количество знаков, выводимых после десятичной запятой.

### Популярные спецификаторы типа (для функций семейства `printf`/`scanf`)
* `%d` или `%i` — знаковые целые числа (`int`).
* `%f` — вещественные числа с плавающей точкой (`float`).
* `%lf` — вещественные числа двойной точности (`double` — применяется в основном для ввода через `scanf`).
* `%c` — одиночный символ (`char`).
* `%s` — строка символов.

### Функция безопасного форматированного ввода: `scanf_s`
Заменяет устаревшую и небезопасную функцию `scanf` в современных компиляторах (защита от переполнения буфера).

* **Синтаксис вызова:**
  ```cpp
  scanf_s("строка_формата", &переменная_1, &переменная_2, ...);
  ```
* ⚠️ **Важное правило:** Аргументами функции должны выступать не сами переменные, а их **адреса в памяти**, для чего перед именем переменной обязательно ставится оператор взятия адреса — амперсанд `&`. Если считывается строка или символ (`%c`, `%s`), в `scanf_s` дополнительно передается размер выделенного буфера.

```cpp
// Пример использования форматированного ввода на C++
#include <cstdio> // Подключение библиотеки ввода-вывода C-style

int main() {
    int age;
    float salary;

    // Запрос ввода у пользователя
    printf("Введите ваш возраст и зарплату через пробел: ");
    
    // Считывание данных с явным указанием адресов (&) переменных
    scanf_s("%d %f", &age, &salary);
    
    // Вывод с ограничением точности до двух знаков после запятой
    printf("Возраст: %d лет. Зарплата: %.2f рублей.\n", age, salary);
    
    return 0;
}
```
