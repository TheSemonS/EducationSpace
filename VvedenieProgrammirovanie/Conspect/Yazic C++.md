## 1. Понятие языка программирования и компиляции

> **Программа** — это алгоритм, записанный на языке программирования и предназначенный для исполнения компьютером.

* Преобразование исходного текста в машинный код выполняет **транслятор** (компилятор или интерпретатор).
> **Компилятор** — осуществляет перевод исходного кода в операции, выполняемые компьютером.

### Схема обработки кода компилятором
1. 📄 **Исходный код**
2. 🔍 **Синтаксический контроль** *(при обнаружении ошибок — возврат к редактированию)*
3. ⚙️ **Генератор машинного кода**
4. 🚀 **Исполняемая программа**

### Основные задачи компилятора
- [ ] Проверка программы на синтаксические ошибки.
- [ ] Создание машинного кода (выполняется строго при условии отсутствия ошибок в исходном коде).

### Три составляющие языка программирования
* **Алфавит** — фиксированный набор символов.
* **Синтаксис** — правила использования символов и построения конструкций.
* **Семантика** — смысловое истолкование языковых конструкций.

### Историческая справка
* **Деннис Ритчи (Dennis M. Ritchie):** разработал язык C в 1972 году.
* **Бьёрн Страуструп (Bjarne Stroustrup):** создал объектно-ориентированное расширение C++ в 1979 году.
* **Классические труды:** Книги Б. Кернигана и Д. Ритчи (издания 1978 и 1985 годов).

## 2. Стандарты и методология разработки

### Стандарты языков семейства C/C++
* **C89** — первый официальный стандарт ANSI/ISO для языка C.
* **C++ (на базе C89)** — объектно-ориентированная версия языка, получившая стандартизацию ANSI/ISO.
* **C++99** — развитие стандарта на базе C85 с добавлением новых программных средств.
* **C++11 (ISO/IEC 14882:2011)** — крупный стандарт, принесший множество качественных улучшений в язык.

### Принципы структурного программирования
> **Теорема Бёма — Якопини:** любая программа, которая строится без использования безусловного оператора `goto`, может быть написана с помощью всего трех базовых управляющих конструкций:
> * Последовательность (линейное выполнение)
> * Ветвление (условный выбор)
> * Цикл (повторение действий)
> * Подпрограммы

* 💡 **Методология разработки:** создание программного обеспечения ведется пошагово по принципу **«сверху вниз»**.

## 3. Элементы текста программы

> **Лексема** — минимальная единица текста программы, которая при компиляции воспринимается как единое целое и не может быть разделена на более мелкие элементы.

* **Классификация лексем:**
  * Свободно выбираемые идентификаторы
  * Служебные (ключевые) слова
  * Константы
  * Строковые литералы (строки)
  * Операции (знаки операций)
  * Разделители

### Компоненты кода
* **Препроцессорные директивы:** управляют текстовым преобразованием кода программы до начала её фактической компиляции.
* **Описания (объявления):** уведомляют компилятор о свойствах и именах объектов/функций, которые физически определены далее по тексту программы или в других файлах проекта.
* **Определения:** непосредственно создают и вводят в программу функции и объекты.

## 4. Структура и сборка программы на C++

### Общепринятая структура исходного файла
1. Подключение внешних библиотек и заголовочных файлов.
2. Объявление прототипов функций.
3. Объявление глобальных идентификаторов (переменных).
4. Главная функция программы (`main`).
5. Реализация ранее объявленных функций.

<details>
<summary>🔍 Развернуть схему конвейера сборки (Build Pipeline)</summary>

Процесс получения готового исполняемого файла состоит из следующих шагов:
1. **Исходный текст C++** + **Включаемые файлы (`.h`)** поступают на вход препроцессору.
2. **Препроцессор** формирует полный развернутый текст программы.
3. **Компилятор** обрабатывает текст и генерирует **Объектный код программы**.
4. **Компоновщик (Линкер)** соединяет **объектный код** со **Стандартными библиотеками**.
5. На выходе формируется готовая **Исполняемая программа**.
</details>

### Логический состав проекта
* **Проект:** состоит из одного или нескольких файлов.
* **Файлы:** содержат описания данных и исполняемых функций.
* **Функция:** обособленный участок кода, предназначенный для решения конкретной подзадачи.
* **Главная функция (`main`):** обязательная точка входа в любую программу.
