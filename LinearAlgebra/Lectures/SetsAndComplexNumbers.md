## 1. Теория множеств

> **Множество** — это совокупность определенных, различимых между собой объектов, мыслимых как единое целое. Объекты, составляющие множество, называются его **элементами**.

* $A, B, C, S, P$ — обозначения множеств (заглавные латинские буквы).
* $x, y, z, a, b, c$ — обозначения элементов (строчные латинские буквы).

### Математические обозначения и кванторы
* $\forall$ — квантор всеобщности («для любого», «для каждого»).
* $\exists$ — квантор существования («существует», «найдется»).
* $\exists!$ — существует единственный элемент.
* $:$ или $\mid$ — знак условия («такой, что»).
* $\subset$ — знак включения множества (подмножество).
* $\in$ — знак принадлежности элемента множеству ($x \in A$ — элемент $x$ находится в множестве $A$).
* $\notin$ — знак непренадлежности элемента множеству ($x \notin A$).
* $\emptyset$ — пустое множество (не содержащее ни одного элемента).
* $U$ — универсальное множество (содержащее все возможные объекты рассматриваемого класса).
* $\blacktriangle$ / $\blacksquare$ — символы начала и окончания доказательства/решения соответственно.

---

### Отношения между множествами и операции

> **Подмножество (Включение)** — множество $A$ содержится в множестве $B$ (является его подмножеством), если каждый элемент множества $A$ одновременно является элементом множества $B$.
> 
> Запись: $A \subset B \iff \forall x \in A \Rightarrow x \in B$

> **Равенство множеств** — множества $A$ и $B$ называются равными, если они состоят из одних и тех же элементов (то есть $A \subset B$ и $B \subset A$).
> 
> Запись: $A = B \iff (A \subset B) \land (B \subset A)$

*Пример:* Если $A = \{1, 2, 3\}$ и $B = \{2, 1, 3\}$, то $A \subset B$ и $B \subset A$, следовательно, $A = B$.

> **Теорема о пустом множестве:** Пустое множество $\emptyset$ является подмножеством любого множества $A$.
> 
> $$\forall A: \emptyset \subset A$$

#### Основные операции над множествами
Ниже представлены аналитические определения операций и их геометрическая интерпретация через диаграммы Эйлера-Венна.

| Операция | Математическая запись | Описание |
| :--- | :--- | :--- |
| **Объединение** ($A \cup B$) | $\{x \mid x \in A \lor x \in B\}$ | Элементы, принадлежащие хотя бы одному из множеств. |
| **Пересечение** ($A \cap B$) | $\{x \mid x \in A \land x \in B\}$ | Общие элементы множеств $A$ и $B$. |
| **Разность** ($A \setminus B$) | $\{x \mid x \in A \land x \notin B\}$ | Элементы, входящие в $A$, но не входящие в $B$. |
| **Дополнение** ($\bar{A}$) | $\{x \mid x \in U \land x \notin A\}$ | Все элементы универсального множества, не входящие в $A$. |

### Декартово (прямое) произведение множеств

> **Упорядоченная пара $(x, y)$** — пара элементов, в которой важен порядок их следования. В отличие от множеств, для пар выполняется: $(1, 2) \neq (2, 1)$. Набор из $n$ элементов $(x_1, x_2, \dots, x_n)$ называется упорядоченным $n$-набором (или кортежем).

> **Декартово произведение $A \times B$** — множество всех возможных упорядоченных пар $(x, y)$, где первый элемент принадлежит множеству $A$, а второй — множеству $B$.
> 
> $$A \times B = \{(x, y) \mid x \in A \land y \in B\}$$

*Пример:* 
Пусть $A = \{1, 2, 3, 4\}$, а $B = \{P, Q\}$. Тогда:
$$A \times B = \{(1,P), (2,P), (3,P), (4,P), (1,Q), (2,Q), (3,Q), (4,Q)\}$$

Если множество умножается само на себя, получается его декартов квадрат:
$$A^2 = A \times A = \{(x, y) \mid x \in A \land y \in A\}$$

## 2. Числовые множества

В математике выделяют следующие фундаментальные вложенные структуры данных:
$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$

1. **$\mathbb{N}$ (Натуральные числа)** — числа, используемые при счете предметов: $\mathbb{N} = \{1, 2, 3, 4, \dots\}$
2. **$\mathbb{Z}$ (Целые числа)** — натуральные, им противоположные и ноль: $\mathbb{Z} = \{\dots, -2, -1, 0, 1, 2, \dots\}$
3. **$\mathbb{Q}$ (Рациональные числа)** — числа, представимые в виде обыкновенной дроби: 
   $$\mathbb{Q} = \left\{ \frac{m}{n} \ \big|\ m \in \mathbb{Z},\ n \in \mathbb{N} \right\}$$
4. **$\mathbb{R}$ (Действительные / Вещественные числа)** — объединение рациональных и иррациональных чисел (все точки числовой прямой).
5. **$\mathbb{C}$ (Комплексные числа)** — расширение множества вещественных чисел для решения уравнений вида $x^2 = -1$.

## 3. Комплексные числа

> **Комплексное число $Z$** в алгебраической форме — это выражение вида:
> 
> $$Z = x + iy$$
> 
> где $x, y \in \mathbb{R}$, а $i$ — **мнимая единица**, удовлетворяющая условию $i^2 = -1$.

* $x = \text{Re}(Z)$ — действительная (вещественная) часть комплексного числа.
* $y = \text{Im}(Z)$ — мнимая часть комплексного числа.

**Частные случаи:**
* Если $x = 0 \rightarrow Z = iy$ — *чисто мнимое число*.
* Если $y = 0 \rightarrow Z = x \in \mathbb{R}$ — *чисто действительное число*.

---

### Алгебраические операции над комплексными числами

Пусть заданы два комплексных числа: $Z_1 = 3 - 2i$ и $Z_2 = 2 + i$.

1. **Сложение:** Складываются отдельно вещественные и мнимые части.
   $$Z_1 + Z_2 = (3 + 2) + (-2 + 1)i = 5 - i$$
2. **Вычитание:**
   $$Z_1 - Z_2 = (3 - 2) + (-2 - 1)i = 1 - 3i$$
3. **Умножение:** Раскрытие скобок с учетом $i^2 = -1$.
   $$Z_1 \cdot Z_2 = (3 - 2i)(2 + i) = 6 + 3i - 4i - 2i^2 = 6 - i - 2(-1) = 8 - i$$
4. **Деление:** Умножение числителя и знаменателя на число, сопряженное знаменателю.
   $$\frac{Z_1}{Z_2} = \frac{3 - 2i}{2 + i} = \frac{(3 - 2i)(2 - i)}{(2 + i)(2 - i)} = \frac{6 - 3i - 4i + 2i^2}{4 - i^2} = \frac{4 - 7i}{4 - (-1)} = \frac{4 - 7i}{5} = \frac{4}{5} - \frac{7}{5}i$$

> **Комплексно-сопряженное число** для $Z = x + iy$ — это число, отличающееся только знаком мнимой части. Обозначается $\bar{Z}$:
> 
> $$\bar{Z} = x - iy$$

### Геометрический смысл комплексного числа
Комплексное число $Z = x + iy$ изображается на комплексной плоскости в виде точки с координатами $(x, y)$ или радиус-вектора, проведенного из начала координат в эту точку. Сложение и вычитание комплексных чисел полностью эквивалентно сложению и вычитанию векторов на плоскости по правилу параллелограмма.

---

### Тригонометрическая форма комплексного числа

Переход из декартовых координат $(x, y)$ в полярные координаты $(r, \varphi)$:

> **Модуль комплексного числа ($r$ или $|Z|$)** — длина радиус-вектора, проведенного из начала координат к точке $Z$:
> 
> $$r = |Z| = \sqrt{x^2 + y^2}$$

> **Аргумент комплексного числа ($\text{Arg } Z$)** — угол между положительным направлением действительной оси $\text{Re}(Z)$ и радиус-вектором точки. Определен неоднозначно (с точностью до $2\pi k$).
> 
> Главное значение аргумента обозначается $\arg z$ и лежит в полуинтервале $(-\pi; \pi]$:
> 
> $$\arg z = \begin{cases} \arctan\frac{y}{x}, & \text{если } x > 0 \\ \arctan\frac{y}{x} + \pi, & \text{если } x < 0, y \ge 0 \\ \arctan\frac{y}{x} - \pi, & \text{если } x < 0, y < 0 \\ \frac{\pi}{2}, & \text{если } x = 0, y > 0 \\ -\frac{\pi}{2}, & \text{если } x = 0, y < 0 \end{cases}$$

**Тригонометрическая формула комплексного числа:**
$$Z = r(\cos\varphi + i\sin\varphi)$$

*Связь с показательной формой (формула Эйлера):* $r(\cos\varphi + i\sin\varphi) = r \cdot e^{i\varphi}$

#### Пример перевода в тригонометрическую форму
Перевести в тригонометрическую форму число $Z = -2 + 2i$:
1. Находим модуль: $r = \sqrt{(-2)^2 + 2^2} = \sqrt{8} = 2\sqrt{2}$.
2. Находим аргумент: Точка лежит во II четверти ($x < 0, y > 0$).
   $$\tan\varphi = \frac{2}{-2} = -1 \implies \varphi = -\frac{\pi}{4} + \pi = \frac{3\pi}{4}$$
3. Результат: $Z = 2\sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)$.

### Действия над числами в тригонометрической форме

Пусть $Z_1 = r_1(\cos\varphi_1 + i\sin\varphi_1)$ и $Z_2 = r_2(\cos\varphi_2 + i\sin\varphi_2)$.

* **Умножение:** Модули перемножаются, аргументы складываются.
  $$Z_1 \cdot Z_2 = r_1 r_2 \left[\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\right]$$
* **Деление:** Модули делятся, аргументы вычитаются.
  $$\frac{Z_1}{Z_2} = \frac{r_1}{r_2} \left[\cos(\varphi_1 - \varphi_2) + i\sin(\varphi_1 - \varphi_2)\right]$$

$$Z_1 \cdot Z_2 = r_1(\cos\varphi_1 + i\sin\varphi_1) \cdot r_2(\cos\varphi_2 + i\sin\varphi_2) =$$
$$= r_1 r_2 (\cos\varphi_1\cos\varphi_2 + i\cos\varphi_1\sin\varphi_2 + i\sin\varphi_1\cos\varphi_2 + i^2\sin\varphi_1\sin\varphi_2) =$$

$$= r_1 r_2 ((\cos\varphi_1\cos\varphi_2 - \sin\varphi_1\sin\varphi_2) + i(\sin\varphi_1\cos\varphi_2 + \cos\varphi_1\sin\varphi_2)) =$$
$$= r_1 r_2 (\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)) \quad \blacksquare$$

> **Формула Муавра** (возведение в $n$-ю степень):
> 
> $$Z^n = r^n(\cos(n\varphi) + i\sin(n\varphi)), \quad n \in \mathbb{Z}$$

### Извлечение корня натуральной степени из комплексного числа

> **Корень $n$-й степени** из комплексного числа $Z$ — это такое комплексное число $W$, что $W^n = Z$.
> 
> Запись: $\sqrt[n]{Z} = W \iff W^n = Z$

Если $Z = r(\cos\varphi + i\sin\varphi)$, то извлечение корня имеет ровно $n$ различных значений и вычисляется по формуле:
$$\sqrt[n]{Z} = \sqrt[n]{r}\left(\cos\frac{\varphi + 2\pi k}{n} + i\sin\frac{\varphi + 2\pi k}{n}\right), \quad k = 0, 1, 2, \dots, n-1$$

Геометрически все $n$ значений корня лежат на окружности радиуса $R = \sqrt[n]{r}$ с центром в начале координат и образуют вершины правильного $n$-угольника.

#### Пример: Вычислить $\sqrt[4]{-8 + 8\sqrt{3}i}$

Пусть $Z = -8 + 8\sqrt{3}i$. Нам нужно найти значения для $n = 4$.

* **Модуль:** 
  $$r = \sqrt{(-8)^2 + (8\sqrt{3})^2} = \sqrt{64 + 64 \cdot 3} = \sqrt{256} = 16$$
* **Аргумент:** Точка лежит во II четверти ($x = -8, y = 8\sqrt{3}$).
  $$\tan\varphi = \frac{8\sqrt{3}}{-8} = -\sqrt{3} \implies \varphi = \frac{2\pi}{3}$$
* **Общая тригонометрическая форма корня:**
  $$\sqrt[4]{Z} = \sqrt[4]{16}\left(\cos\frac{\frac{2\pi}{3} + 2\pi k}{4} + i\sin\frac{\frac{2\pi}{3} + 2\pi k}{4}\right) = 2\left(\cos\left(\frac{\pi}{6} + \frac{\pi k}{2}\right) + i\sin\left(\frac{\pi}{6} + \frac{\pi k}{2}\right)\right)$$

Для получения всех 4-х корней последовательно подставим $k = 0, 1, 2, 3$:

* **При $k = 0$:** $W_0 = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right) = 2\left(\frac{\sqrt{3}}{2} + i\frac{1}{2}\right) = \sqrt{3} + i$
* **При $k = 1$:** $W_1 = 2\left(\cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3}\right) = 2\left(-\frac{1}{2} + i\frac{\sqrt{3}}{2}\right) = -1 + \sqrt{3}i$
* **При $k = 2$:** $W_2 = 2\left(\cos\frac{7\pi}{6} + i\sin\frac{7\pi}{6}\right) = 2\left(-\frac{\sqrt{3}}{2} - i\frac{1}{2}\right) = -\sqrt{3} - i$
* **При $k = 3$:** $W_3 = 2\left(\cos\frac{5\pi}{3} + i\sin\frac{5\pi}{3}\right) = 2\left(\frac{1}{2} - i\frac{\sqrt{3}}{2}\right) = 1 - \sqrt{3}i$
