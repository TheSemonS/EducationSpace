## Комплексные числа: основные понятия

### Определение
Комплексное число записывается в алгебраической форме:

```math
z = x + yi, \qquad x, y \in \mathbb{R}, \qquad i^2 = -1
```

Здесь $`x = \operatorname{Re} z`$ — действительная часть, $`y = \operatorname{Im} z`$ — мнимая часть, $`i`$ — мнимая единица.

### Геометрическая интерпретация
Число $`z`$ изображается точкой (или вектором) на комплексной плоскости с координатами $`(x; y)`$. По горизонтальной оси откладывается $`\operatorname{Re} z`$ (действительная ось), по вертикальной — $`\operatorname{Im} z`$ (мнимая ось).

> [!NOTE]
> Здесь нужен рисунок: комплексная плоскость с осями $`\operatorname{Re} z`$ и $`\operatorname{Im} z`$. Вектор $`z`$ из начала координат в точку $`(x; y)`$, его длина $`r`$ и угол $`\varphi`$ с положительным направлением действительной оси. Симметрично относительно действительной оси изображён вектор $`\overline{z}`$ (сопряжённое число) с координатами $`(x; -y)`$.

### Сопряжённое число
Числу $`z = x + yi`$ сопоставляется сопряжённое число $`\overline{z} = x - yi`$. На плоскости оно симметрично $`z`$ относительно действительной оси: модуль тот же, аргумент противоположный по знаку.

## Тригонометрическая форма комплексного числа

### Модуль и аргумент
Модуль $`r`$ — длина вектора $`z`$, аргумент $`\varphi`$ — угол между вектором и положительным направлением действительной оси:

```math
r = \sqrt{x^2 + y^2}, \qquad \operatorname{tg} \varphi = \frac{y}{x}, \quad x \ne 0
```

Из определения синуса и косинуса следует связь координат с $`r`$ и $`\varphi`$:

```math
\begin{cases} x = r\cos\varphi \\ y = r\sin\varphi \end{cases}
```

Число $`\varphi`$ называется аргументом комплексного числа. При $`x = 0`$ аргумент находят по положению точки на мнимой оси, а при $`x < 0`$ угол выбирают с учётом четверти, в которой лежит точка (одного значения $`\operatorname{tg} \varphi`$ недостаточно).

### Тригонометрическая форма

```math
z = r\left(\cos\varphi + i\sin\varphi\right)
```

## Действия над числами в тригонометрической форме

Пусть $`z_1 = r_1(\cos\varphi_1 + i\sin\varphi_1)`$ и $`z_2 = r_2(\cos\varphi_2 + i\sin\varphi_2)`$, причём $`z_1, z_2 \ne 0`$.

### Умножение
Модули перемножаются, аргументы складываются:

```math
z_1 \cdot z_2 = r_1 r_2\left(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\right)
```

### Деление
Модули делятся, аргументы вычитаются:

```math
\frac{z_1}{z_2} = \frac{r_1}{r_2}\left(\cos(\varphi_1 - \varphi_2) + i\sin(\varphi_1 - \varphi_2)\right)
```

### Возведение в степень (формула Муавра)

```math
z^n = r^n\left(\cos(n\varphi) + i\sin(n\varphi)\right)
```

### Извлечение корня $`n`$-й степени

```math
\sqrt[n]{z} = \sqrt[n]{r}\left(\cos\left(\frac{\varphi}{n} + \frac{2\pi}{n}k\right) + i\sin\left(\frac{\varphi}{n} + \frac{2\pi}{n}k\right)\right), \qquad k = 0, 1, 2, \dots, n-1
```

Корень $`n`$-й степени из ненулевого числа имеет ровно $`n`$ различных значений, соответствующих $`k = 0, 1, \dots, n-1`$.

## Практические задания (стр. 19)

Задачи: №2 (а, б, г); №3 (а, б); №4 (а, б); №6 (а, б).

### №2. Записать число в тригонометрической форме

#### а) $`z = -2`$

Точка лежит на отрицательной части действительной оси, поэтому $`r = 2`$, $`\varphi = \pi`$.

> [!NOTE]
> Здесь нужен рисунок: вектор из начала координат в точку $`-2`$ на действительной оси, угол $`\varphi`$ отложен от положительного направления оси до вектора.

```math
z = 2\left(\cos\pi + i\sin\pi\right)
```

#### б) $`z = 3i`$

Точка лежит на положительной части мнимой оси, поэтому $`r = 3`$, $`\varphi = \dfrac{\pi}{2}`$.

```math
z = 3\left(\cos\frac{\pi}{2} + i\sin\frac{\pi}{2}\right)
```

#### г) $`z = 1 - i\sqrt{3}`$

Здесь $`x = 1`$, $`y = -\sqrt{3}`$. Точка лежит в четвёртой четверти.

```math
r = \sqrt{1 + 3} = \sqrt{4} = 2, \qquad \operatorname{tg}\varphi = -\sqrt{3}, \qquad \varphi = -\frac{\pi}{3}
```

Значение $`\varphi = -\dfrac{\pi}{3}`$ подходит, так как угол $`-\dfrac{\pi}{3}`$ лежит в четвёртой четверти.

```math
z = 2\left(\cos\left(-\frac{\pi}{3}\right) + i\sin\left(-\frac{\pi}{3}\right)\right)
```

> [!NOTE]
> Здесь нужен рисунок: вектор в четвёртой четверти в точку $`(1; -\sqrt{3})`$, угол $`\varphi`$ отложен по часовой стрелке от положительного направления действительной оси.

### №3. Действия над числами

Даны числа $`z_1 = 1 - i\sqrt{3}`$ и $`z_2 = \sqrt{3} + i`$.

> [!NOTE]
> Здесь нужен рисунок: на комплексной плоскости изображены векторы $`\overline{z_1}`$ (в точку $`(1; \sqrt{3})`$) и $`z_2`$ (в точку $`(\sqrt{3}; 1)`$).

#### а) Вычислить $`\left(\dfrac{\overline{z_1}}{z_2}\right)^2`$

Сопряжённое число:

```math
\overline{z_1} = 1 + i\sqrt{3}
```

Для $`\overline{z_1}`$: $`x_1 = 1`$, $`y_1 = \sqrt{3}`$, $`\operatorname{tg}\varphi = \sqrt{3}`$, $`r = 2`$, $`\varphi = \dfrac{\pi}{3}`$.

Для $`z_2`$: $`x_2 = \sqrt{3}`$, $`y_2 = 1`$, $`\operatorname{tg}\varphi = \dfrac{1}{\sqrt{3}}`$, $`r = 2`$, $`\varphi = \dfrac{\pi}{6}`$.

```math
\overline{z_1} = 2\left(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}\right), \qquad z_2 = 2\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right)
```

Применяем формулы деления и возведения в степень:

```math
\left(\frac{\overline{z_1}}{z_2}\right)^2 = \left(\frac{2}{2}\right)^2\left(\cos\frac{2\pi}{6} + i\sin\frac{2\pi}{6}\right) = \cos\frac{\pi}{3} + i\sin\frac{\pi}{3}
```

#### б) Вычислить $`\overline{z_1 \cdot z_2}`$

Запишем $`z_1`$ в тригонометрической форме (его аргумент противоположен аргументу $`\overline{z_1}`$):

```math
z_1 = 2\left(\cos\left(-\frac{\pi}{3}\right) + i\sin\left(-\frac{\pi}{3}\right)\right)
```

Произведение:

```math
\begin{aligned}
z_1 \cdot z_2 &= 4\left(\cos\left(-\frac{\pi}{3} + \frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{3} + \frac{\pi}{6}\right)\right) \\
&= 4\left(\cos\left(-\frac{\pi}{6}\right) + i\sin\left(-\frac{\pi}{6}\right)\right)
\end{aligned}
```

Сопряжённое число имеет тот же модуль и противоположный аргумент:

```math
\overline{z_1 \cdot z_2} = 4\left(\cos\frac{\pi}{6} + i\sin\frac{\pi}{6}\right) = 4\left(\frac{\sqrt{3}}{2} + i\cdot\frac{1}{2}\right) = 2\sqrt{3} + 2i
```

### №4. Возведение в степень

#### а) Вычислить $`(1 + i)^{27}`$

Для $`1 + i`$: $`x = 1`$, $`y = 1`$, $`r = \sqrt{2}`$, $`\operatorname{tg}\varphi = 1`$, $`\varphi = \dfrac{\pi}{4}`$.

```math
z = \sqrt{2}\left(\cos\frac{\pi}{4} + i\sin\frac{\pi}{4}\right)
```

> [!NOTE]
> Здесь нужен рисунок: вектор $`z`$ в первой четверти в точку $`(1; 1)`$ под углом $`\varphi = \dfrac{\pi}{4}`$ к действительной оси.

По формуле Муавра:

```math
z^{27} = \left(\sqrt{2}\right)^{27}\left(\cos\frac{27\pi}{4} + i\sin\frac{27\pi}{4}\right)
```

Так как $`\dfrac{27\pi}{4} = 6\pi + \dfrac{3\pi}{4}`$, а $`\left(\sqrt{2}\right)^{27} = \sqrt{2}\cdot 2^{13}`$:

```math
z^{27} = \sqrt{2}\cdot 2^{13}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right) = \sqrt{2}\cdot 2^{13}\left(-\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right) = -2^{13} + i\cdot 2^{13}
```

### №6. Извлечение корня

#### а) Найти все значения $`\sqrt[3]{1}`$

Представим $`z = 1`$ в тригонометрической форме: $`r = 1`$, $`\varphi = 0`$.

```math
z = \cos 0 + i\sin 0
```

Здесь $`n = 3`$, поэтому $`k = 0, 1, 2`$:

```math
\sqrt[3]{z} = \sqrt[3]{1}\left(\cos\left(\frac{0}{3} + \frac{2\pi}{3}k\right) + i\sin\left(\frac{0}{3} + \frac{2\pi}{3}k\right)\right) = \cos\frac{2\pi k}{3} + i\sin\frac{2\pi k}{3}
```

Вычисляем три значения:

- при $`k = 0`$:

```math
z_0 = 1
```

- при $`k = 1`$:

```math
z_1 = \cos\frac{2\pi}{3} + i\sin\frac{2\pi}{3} = -\frac{1}{2} + i\frac{\sqrt{3}}{2}
```

- при $`k = 2`$:

```math
z_2 = \cos\frac{4\pi}{3} + i\sin\frac{4\pi}{3} = -\frac{1}{2} - i\frac{\sqrt{3}}{2}
```

> [!NOTE]
> Здесь нужен рисунок: единичная окружность на комплексной плоскости. На ней три точки: $`z_0 = 1`$ (на действительной оси), $`z_1`$ (во второй четверти, угол $`\dfrac{2\pi}{3}`$) и $`z_2`$ (в третьей четверти, угол $`\dfrac{4\pi}{3}`$). Точки делят окружность на три равные дуги и образуют правильный треугольник.
